- **함수/폴더**: `asking_price` · [샘플코드](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/asking_price/asking_price.py)

<a id="ccnl_notice"></a>
### 해외주식 실시간체결통보[실시간-009]

- **함수/폴더**: `ccnl_notice` · [샘플코드](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/ccnl_notice/ccnl_notice.py)
- **방식**: WebSocket 구독 (실전 `ws://ops.koreainvestment.com:21000`, 모의 `:31000`)
- **TR_ID**:
  - `H0GSCNI0` — env_dv == real
  - `H0GSCNI9` — env_dv == demo
- **예시**: `msg, columns = ccnl_notice("1", trenv.my_htsid, "real")`

**요청 파라미터** (body.input)

| 필드 | 필수 | 설명 |
|---|:-:|---|
| `tr_key` | Y | 종목코드 |

**TR_ID/동작 결정 인자** (샘플 함수 인자)

- `tr_type` (필수): 등록/해제
- `env_dv` (필수): 실전모의구분 (ex. real:실전, demo:모의)

### 해외주식 미국주간주문 [v1_해외주식-026]

- **함수/폴더**: `daytime_order` · [샘플코드](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/daytime_order/daytime_order.py)
- **Method / URL**: `POST /uapi/overseas-stock/v1/trading/daytime-order`
- **TR_ID**:
  - `TTTS6036U` — order_dv == buy
  - `TTTS6037U` — order_dv == sell
- **예시**: `df = daytime_order(order_dv="buy", cano=trenv.my_acct, acnt_prdt_cd=trenv.my_prod, ovrs_excg_cd="NASD", pdno="AAPL", ord_qty="10", ovrs_ord_unpr="150.00", ctac_tlno="01012345678", mgco_aptm_odno="", ord_svr_dvsn_cd="0", ord_dvsn="00")`

**요청 파라미터** (Body(JSON))

| 필드 | 필수 | 설명 |
|---|:-:|---|
| `CANO` | Y | 계좌번호 체계(8-2)의 앞 8자리 |
| `ACNT_PRDT_CD` | Y | 계좌번호 체계(8-2)의 뒤 2자리 |
| `OVRS_EXCG_CD` | Y | NASD:나스닥 / NYSE:뉴욕 / AMEX:아멕스 |
| `PDNO` | Y | 종목코드 |
| `ORD_QTY` | Y | 해외거래소 별 최소 주문수량 및 주문단위 확인 필요 |
| `OVRS_ORD_UNPR` | Y | 소수점 포함, 1주당 가격 * 시장가의 경우 1주당 가격을 공란으로 비우지 않음 "0"으로 입력 |
| `CTAC_TLNO` | Y | " " |
| `MGCO_APTM_ODNO` | Y | " " |
| `ORD_SVR_DVSN_CD` | Y | "0" |
| `ORD_DVSN` | Y | [미국 매수/매도 주문]  00 : 지정가  * 주간거래는 지정가만 가능 |

**TR_ID/동작 결정 인자** (샘플 함수 인자)

- `order_dv` (필수): 주문구분 buy(매수) / sell(매도)

<details><summary>응답 필드 (3개)</summary>

| 필드 | 설명 |
|---|---|
| `KRX_FWDG_ORD_ORGNO` | 한국거래소전송주문조직번호 |
| `ODNO` | 주문번호 |
| `ORD_TMD` | 주문시각 |

</details>

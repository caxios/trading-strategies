- **함수/폴더**: `daily_ccnl` · [샘플코드](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_futureoption/daily_ccnl/daily_ccnl.py)
- **Method / URL**: `GET /uapi/overseas-futureoption/v1/quotations/daily-ccnl`
- **TR_ID**: `HHDFC55020100`
- **예시**: `df1, df2 = daily_ccnl(srs_cd="6AM24", exch_cd="CME", start_date_time="", close_date_time="20240402", qry_tp="Q", qry_cnt="30", qry_gap="", index_key="")`

**요청 파라미터** (Query)

| 필드 | 필수 | 설명 |
|---|:-:|---|
| `SRS_CD` | Y | 종목코드 (예: 6AM24) |
| `EXCH_CD` | Y | 거래소코드 (예: CME) |
| `START_DATE_TIME` | Y | 조회시작일시 (공백) |
| `CLOSE_DATE_TIME` | Y | 조회종료일시 (예: 20240402) |
| `QRY_TP` | Y | 조회구분 (Q: 최초조회시, P: 다음키(INDEX_KEY) 입력하여 조회시) |
| `QRY_CNT` | Y | 요청개수 (예: 30, 최대 40) |
| `QRY_GAP` | Y | 묶음개수 (공백, 분만 사용) |
| `INDEX_KEY` | Y | 이전조회KEY (공백) |

# KIS Open API 문서 (한국투자증권)

한국투자증권 Open API **전체 334개**(REST 274 + WebSocket 60)를 상품·분류별로 정리한 문서.

- **출처**: 공식 GitHub [`koreainvestment/open-trading-api`](https://github.com/koreainvestment/open-trading-api)의 `examples_llm/` 샘플코드에서 자동 추출 (URL, TR_ID, 요청 파라미터, 응답 필드)
- **포털 원문**: https://apiportal.koreainvestment.com (JS 렌더링 페이지라 원문 대신 공식 샘플을 기준으로 함)
- **추출 기준일**: 2026-10-23

## 먼저 읽을 것

👉 **[00_공통_가이드.md](00_공통_가이드.md)** — 도메인, 토큰 발급, 공통 헤더, 실전/모의 TR_ID 규칙, 연속조회, 호출 제한, 웹소켓 프로토콜

## 찾는 방법

- **API 이름이나 TR_ID로 찾기**: [INDEX.csv](INDEX.csv) (엑셀로 열기 가능) 또는 `grep -r "FHPUP02100000" KIS_API_docs/`
- **코드에서 쓰기**: [apis.json](apis.json) — 전체 명세를 기계가 읽기 좋은 JSON으로 저장
- **각 문서 구성**: 분류별 목록 표 → API마다 Method/URL, TR_ID(실전/모의 조건별), 요청 파라미터 표, 응답 필드(접힘), 공식 샘플코드 링크

## 문서 갱신

KIS가 API를 추가하거나 변경하면 아래 순서로 다시 만든다.

```bash
git clone --depth 1 https://github.com/koreainvestment/open-trading-api.git /tmp/kis
python -I KIS_API_docs/_tools/parse_kis.py /tmp/kis apis_raw.json
python -I KIS_API_docs/_tools/gen_docs.py apis_raw.json KIS_API_docs
```

(`00_공통_가이드.md`와 `README.md`는 직접 작성한 문서라 스크립트가 덮어쓰지 않음. 목차가 바뀌면 `_toc.md` 내용을 README에 반영)

## 주의

- 자동 추출이라 일부 설명이 비어 있거나 샘플 docstring 표현을 그대로 옮긴 곳이 있음. 실제 주문 전에는 포털 원문을 한 번 더 확인할 것
- 모의투자는 지원하지 않는 API가 많음 (TR_ID 목록에 `V...`가 없으면 실전 전용일 가능성 높음)

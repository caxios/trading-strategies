<a id="buy"></a>
### 장내채권 매수주문

- **함수/폴더**: `buy` · [샘플코드](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_bond/buy/buy.py)
- **Method / URL**: `POST /uapi/domestic-bond/v1/trading/buy`
- **TR_ID**: `TTTC0952U`
- **예시**: `df = buy(cano=trenv.my_acct, acnt_prdt_cd=trenv.my_prod, pdno="KR1234567890", ord_qty2="10", bond_ord_unpr="10000", samt_mket_ptci_yn="N", bond_rtl_mket_yn="Y")`

**요청 파라미터** (Body(JSON))

| 필드 | 필수 | 설명 |
|---|:-:|---|
| `CANO` | Y | 종합계좌번호 (8자리) |
| `ACNT_PRDT_CD` | Y | 계좌상품코드 (2자리) |
| `PDNO` | Y | 상품번호 (12자리) |
| `ORD_QTY2` | Y | 주문수량2 (19자리) |
| `BOND_ORD_UNPR` | Y | 채권주문단가 (182자리) |
| `SAMT_MKET_PTCI_YN` | Y | 소액시장참여여부 ('Y' or 'N') |
| `BOND_RTL_MKET_YN` | Y | 채권소매시장여부 ('Y' or 'N') |
| `IDCR_STFNO` |  | 유치자직원번호 (6자리). Defaults to "". |
| `MGCO_APTM_ODNO` |  | 운용사지정주문번호 (12자리). Defaults to "". |
| `ORD_SVR_DVSN_CD` |  | 주문서버구분코드. Defaults to "". |
| `CTAC_TLNO` |  | 연락전화번호. Defaults to "". |

<details><summary>응답 필드 (3개)</summary>

| 필드 | 설명 |
|---|---|
| `KRX_FWDG_ORD_ORGNO` | 한국거래소전송주문조직번호 |
| `ODNO` | 주문번호 |
| `ORD_TMD` | 주문시각 |

</details>

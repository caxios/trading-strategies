# KIS Open API 공통 가이드

모든 API에 공통으로 적용되는 규칙. 공식 저장소 `examples_llm/kis_auth.py` 기준으로 정리.

## 1. 준비물

1. 한국투자증권 계좌 개설 → [KIS Developers](https://apiportal.koreainvestment.com)에서 Open API 신청
2. **앱키(appkey) / 앱시크릿(appsecret)** 발급 — 실전투자용과 모의투자용은 **별도 키**
3. 계좌번호: 앞 8자리(`CANO`) + 뒤 2자리 상품코드(`ACNT_PRDT_CD`)
   - `01` 종합계좌 · `03` 국내선물옵션 · `08` 해외선물옵션 · `22` 개인연금 · `29` 퇴직연금
4. HTS ID (체결통보 웹소켓 구독 등에 필요)

공식 샘플은 `~/KIS/config/kis_devlp.yaml`에 위 값을 넣어 사용:

```yaml
my_app: "실전 앱키"
my_sec: "실전 앱시크릿"
paper_app: "모의 앱키"
paper_sec: "모의 앱시크릿"
my_htsid: "HTS ID"
my_acct_stock: "증권계좌 8자리"
my_acct_future: "선물옵션계좌 8자리"
my_paper_stock: "모의 증권계좌 8자리"
my_paper_future: "모의 선물옵션계좌 8자리"
my_prod: "01"
```

> 키/계좌정보는 절대 git에 커밋하지 말 것.

## 2. 도메인

| 구분 | REST | WebSocket |
|---|---|---|
| 실전 | `https://openapi.koreainvestment.com:9443` | `ws://ops.koreainvestment.com:21000` |
| 모의 | `https://openapivts.koreainvestment.com:29443` | `ws://ops.koreainvestment.com:31000` |

## 3. 인증

### 접근토큰 (REST용)

```
POST {domain}/oauth2/tokenP
Content-Type: application/json

{"grant_type": "client_credentials", "appkey": "...", "appsecret": "..."}
```

응답: `access_token`, `token_type`(Bearer), `expires_in`, `access_token_token_expired`

- 유효기간 **24시간**. 재발급은 **1분에 1회** 제한 → 파일 등에 저장해서 재사용할 것

### 웹소켓 접속키

```
POST {domain}/oauth2/Approval
{"grant_type": "client_credentials", "appkey": "...", "secretkey": "..."}
```

응답: `approval_key` (필드명이 `appsecret`이 아니라 **`secretkey`**인 점 주의)

## 4. REST 요청 헤더

| 헤더 | 값 |
|---|---|
| `content-type` | `application/json; charset=utf-8` |
| `authorization` | `Bearer {access_token}` |
| `appkey` | 앱키 |
| `appsecret` | 앱시크릿 |
| `tr_id` | API별 거래 ID (각 문서의 TR_ID) |
| `tr_cont` | 연속조회 여부 (첫 조회 `""`, 다음 페이지 `"N"`) |
| `custtype` | `P` (개인/법인) · `B` (제휴사) |
| `hashkey` | (선택) POST body 위변조 방지용. `POST /uapi/hashkey`로 발급. 공식 샘플은 사용 안 함 |

- **GET**: 파라미터를 query string으로 전송
- **POST**(주문 등): 파라미터를 JSON body로 전송. 필드명은 **대문자**, 값은 모두 **문자열**

### 실전/모의 TR_ID 규칙

실전 TR_ID가 `T`, `J`, `C`로 시작하면 모의는 첫 글자를 `V`로 바꾼다. 예: `TTTC0012U` → `VTTC0012U`.
시세 조회(`FHK...`, `HHD...` 등)는 대부분 실전/모의 동일. 단, **모의투자에서 지원하지 않는 API가 많음**(문서에 V로 시작하는 TR_ID가 없으면 실전 전용일 가능성 높음).

## 5. 응답 구조

```json
{
  "rt_cd": "0",          // "0"이면 성공
  "msg_cd": "MCA00000",
  "msg1": "정상처리 되었습니다.",
  "output": {...}         // 또는 output1 / output2 (API마다 다름)
}
```

- 응답 헤더 `tr_cont`: `F` 또는 `M`이면 **다음 페이지 있음**, `D`/`E`면 마지막
- 숫자도 문자열로 내려오므로 변환 필요

## 6. 연속조회 (페이징)

1. 첫 요청: 헤더 `tr_cont: ""`, 연속키 파라미터는 빈 값
2. 응답 헤더 `tr_cont`가 `M`/`F`면 → 응답 body의 연속키를 다음 요청 파라미터로 넣고 헤더 `tr_cont: "N"`으로 재요청
3. 연속키 이름은 API마다 다름:
   - 계좌 조회: `CTX_AREA_FK100` / `CTX_AREA_NK100` (응답 `ctx_area_fk100`, `ctx_area_nk100`)
   - 해외 등: `CTX_AREA_FK200`/`NK200`, `FK50`/`NK50` 등
4. 차트 조회(일봉/분봉)는 연속키 대신 **조회 기준일자/시간을 이동**시키며 반복 호출하는 방식이 많음

## 7. 호출 제한 (Rate limit)

- 공식 샘플의 대기값: 실전 **0.05초**, 모의 **0.5초** 간격 → 실전 초당 약 20건, 모의 초당 약 2건 수준
- 초과 시 `EGW00201`(초당 거래건수 초과) 에러 → 재시도 로직 필요
- 토큰 발급은 1분에 1회 제한

## 8. WebSocket (실시간 시세 / 체결통보)

### 구독 요청 메시지

```json
{
  "header": {
    "approval_key": "{approval_key}",
    "custtype": "P",
    "tr_type": "1",          // "1" 등록, "2" 해제
    "content-type": "utf-8"
  },
  "body": {
    "input": {
      "tr_id": "H0STCNT0",   // 실시간 TR_ID
      "tr_key": "005930"     // 종목코드 (체결통보는 HTS ID)
    }
  }
}
```

> 일부 샘플(국내주식 실시간 등) docstring에는 해제가 `"0"`으로 적혀 있지만, 선물옵션 샘플과 공식 backtester 코드는 `"2"`=해제로 사용. **해제는 `"2"`** 기준.

### 수신 데이터

- 첫 글자 `0` 또는 `1` → 실시간 데이터: `암호화여부|TR_ID|데이터건수|값^값^값...`
  - `^`로 구분된 값을 각 문서의 **수신 컬럼 순서**대로 매핑
  - 데이터건수가 2 이상이면 컬럼 수 단위로 잘라서 여러 건 처리
  - 암호화여부 `1`(체결통보 등): 구독 응답으로 받은 `key`, `iv`로 **AES-256-CBC + Base64** 복호화
- 그 외(JSON) → 시스템 메시지(구독 성공/실패, `PINGPONG`)
  - `PINGPONG` 수신 시 **같은 내용을 그대로 돌려보내야** 연결 유지

### 제한

- 세션당 실시간 구독 **최대 41건** 수준(공식 샘플은 40건 초과 시 에러 처리)
- 앱키당 동시 접속 1세션 권장

## 9. 종목/업종 코드 마스터

종목코드, 업종코드(예: 코스피 `0001`, 코스닥 `1001`, 코스피200 `2001`), 해외 종목코드 등은 KIS가 제공하는 마스터 파일을 받아서 사용.
- 공식 저장소 [`stocks_info/`](https://github.com/koreainvestment/open-trading-api/tree/main/stocks_info): 마스터 파일 다운로드/파싱 스크립트(`kis_kospi_code_mst.py`, `sector_code.py`, `overseas_stock_code.py` 등)와 레이아웃(`.h`)
- 포털: API 문서 > 종목정보파일

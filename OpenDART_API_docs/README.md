# OpenDART API 문서 (금융감독원 전자공시)

금융감독원 OpenDART 오픈API **전체 85개**를 분류별로 정리한 문서.

- **출처**: [OpenDART 개발가이드](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS001) 6개 분류의 목록 페이지와 각 API 상세 페이지를 자동 수집 (기본 정보, 요청 인자, 응답 결과, 테스트 예시값, 메시지 코드, 부가 코드표)
- **수집 기준일**: 2026-10-30
- **다시 만들기**: `python OpenDART_API_docs/_tools/scrape_dart.py --refresh` (받은 HTML은 `_tools/cache/`에 저장, `--refresh` 없이 실행하면 캐시로 문서만 다시 생성). `00_공통_가이드.md`는 직접 작성한 문서라 다시 만들지 않는다

## 먼저 읽을 것

👉 **[00_공통_가이드.md](00_공통_가이드.md)** — 인증키, 요청 형식, 공통 응답(status/message), 메시지 코드, 호출 제한, 고유번호(corp_code) 얻기, 보고서 코드, 파이썬 예제

## 찾는 방법

- **API 이름이나 URL로 찾기**: [INDEX.csv](INDEX.csv) (엑셀로 열기 가능) 또는 `grep -r "fnlttSinglAcntAll" OpenDART_API_docs/`
- **코드에서 쓰기**: [apis.json](apis.json) — 전체 명세를 기계가 읽기 좋은 JSON으로 저장
- **각 문서 구성**: 분류별 목록 표 → API마다 설명, 원문 링크, Method/URL(JSON·XML), 요청 인자 표, 요청 예시 URL, 응답 결과(접힘, 계층 표시)

# OpenDART 공통 가이드

> 출처: OpenDART 개발가이드·오픈API 소개 페이지(https://opendart.fss.or.kr) 내용을 정리 (2026-10-30). 각 API의 상세 명세는 분류별 문서 참고.

## 1. OpenDART란

금융감독원 전자공시시스템(DART)에 제출된 공시를 프로그램으로 받아 쓸 수 있게 한 공개 API다. 개인, 기업, 기관 누구나 쓸 수 있다. 제공 범위는 세 가지다.

- **공시보고서 원문:** XML 형식으로 내려받아 필요한 부분을 직접 추출
- **주요 공시·재무정보:** 사업보고서 주요항목, 주요 재무계정, 지분공시, 주요사항보고서, 증권신고서를 데이터 형식(JSON/XML)으로 바로 사용
- **대용량 재무정보:** 상장법인(유가증권, 코스닥)과 주요 비상장법인(사업보고서 제출대상이면서 IFRS 적용)의 정기보고서 재무제표

API는 6개 분류, 총 85개다.

| 분류 | 개수 | 문서 |
|---|---|---|
| 공시정보 (공시검색, 기업개황, 원본파일, 고유번호) | 4 | [01_공시정보.md](01_공시정보.md) |
| 정기보고서 주요정보 (사업·반기·분기보고서의 주식, 배당, 임원, 직원, 보수 등) | 30 | [02_정기보고서_주요정보.md](02_정기보고서_주요정보.md) |
| 정기보고서 재무정보 (주요계정, 전체 재무제표, XBRL, 재무지표) | 7 | [03_정기보고서_재무정보.md](03_정기보고서_재무정보.md) |
| 지분공시 종합정보 (대량보유, 임원·주요주주 소유) | 2 | [04_지분공시_종합정보.md](04_지분공시_종합정보.md) |
| 주요사항보고서 주요정보 (증자, 감자, 합병, 분할, 자기주식, 전환사채 등) | 36 | [05_주요사항보고서_주요정보.md](05_주요사항보고서_주요정보.md) |
| 증권신고서 주요정보 (지분증권, 채무증권, 합병, 분할 등) | 6 | [06_증권신고서_주요정보.md](06_증권신고서_주요정보.md) |

## 2. 인증키

- 모든 요청에 **`crtfc_key`(인증키, 40자리)** 가 필수다.
- 발급: OpenDART 사이트 → 인증키 신청/관리 → [인증키 신청](https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do) (회원가입 후 발급)
- 관리·사용량 확인: [인증키 관리](https://opendart.fss.or.kr/mng/userApiKeyListView.do), [오픈API 이용현황](https://opendart.fss.or.kr/mng/apiUsageStatusView.do)
- 이 저장소에서는 인증키를 `.env`에 `DART_API_KEY=...` 형태로 넣고 코드에서 읽는 것을 권한다. 키를 코드나 로그에 직접 쓰지 않는다. (현재 `.env`에는 아직 이 키가 없다.)

## 3. 요청 형식

| 항목 | 내용 |
|---|---|
| 기본 주소 | `https://opendart.fss.or.kr/api/` |
| 메서드 | 모두 `GET` |
| 인코딩 | UTF-8 |
| 응답 형식 | URL 확장자로 선택: `{API이름}.json` 또는 `{API이름}.xml` |
| 파일 응답 | 공시서류원본파일(`document.xml`), 고유번호(`corpCode.xml`), 재무제표 원본파일(`fnlttXbrl.xml`)은 **ZIP 파일(바이너리)** 로 내려온다 |
| 인자 전달 | 쿼리스트링. 예: `https://opendart.fss.or.kr/api/company.json?crtfc_key={API_KEY}&corp_code=00126380` |

## 4. 공통 응답 구조

JSON 응답은 항상 `status`와 `message`를 포함하고, 목록형 API는 `list` 배열에 결과를 담는다.

```json
{
  "status": "000",
  "message": "정상",
  "list": [ { "rcept_no": "...", "corp_code": "...", "corp_name": "...", ... } ]
}
```

- **`status`가 `"000"`일 때만 정상**이다. 그 외 값은 아래 메시지 코드를 참고한다.
- **`013`(조회된 데이터 없음)은 오류가 아니다.** 해당 조건에 공시가 없다는 뜻이므로, 반복 수집 코드에서는 정상 흐름으로 처리해야 한다.
- 금액·수량 필드는 개발가이드에 `9,999,999,999` 형식으로 표기되어 있다. 문자열로 오고 천 단위 쉼표가 들어 있을 수 있으므로, 숫자로 바꿀 때 쉼표를 지우고 변환에 실패하는 값(빈 값, 기호 등)은 결측으로 처리하는 것이 안전하다.
- 공시검색 등 페이지가 있는 API는 `page_no`, `page_count`, `total_count`, `total_page`를 함께 돌려준다.

## 5. 메시지 코드

| status | 의미 |
|---|---|
| 000 | 정상 |
| 010 | 등록되지 않은 키입니다. |
| 011 | 사용할 수 없는 키입니다. 오픈API에 등록되었으나, 일시적으로 사용 중지된 키를 통하여 검색하는 경우 발생합니다. |
| 012 | 접근할 수 없는 IP입니다. |
| 013 | 조회된 데이타가 없습니다. |
| 014 | 파일이 존재하지 않습니다. |
| 020 | 요청 제한을 초과하였습니다. 일반적으로는 20,000건 이상의 요청에 대하여 이 에러 메시지가 발생되나, 요청 제한이 다르게 설정된 경우에는 이에 준하여 발생됩니다. |
| 021 | 조회 가능한 회사 개수가 초과하였습니다.(최대 100건) |
| 100 | 필드의 부적절한 값입니다. 필드 설명에 없는 값을 사용한 경우에 발생하는 메시지입니다. |
| 101 | 부적절한 접근입니다. |
| 800 | 시스템 점검으로 인한 서비스가 중지 중입니다. |
| 900 | 정의되지 않은 오류가 발생하였습니다. |
| 901 | 사용자 계정의 개인정보 보유기간이 만료되어 사용할 수 없는 키입니다. 관리자 이메일(opendart@fss.or.kr)로 문의하시기 바랍니다. |

## 6. 호출 제한

- 메시지 코드 020 설명에 따르면 **일반적으로 하루 약 20,000건**을 넘으면 요청이 막힌다. 키마다 한도가 다르게 설정될 수 있다. 정확한 사용량은 [오픈API 이용현황](https://opendart.fss.or.kr/mng/apiUsageStatusView.do)에서 확인한다.
- 다중회사 API(예: 다중회사 주요계정, 다중회사 주요 재무지표)는 `corp_code`를 쉼표로 이어 **최대 100개 회사**까지 한 번에 조회한다. 넘으면 021.
- 공시검색(`list.json`)은 `corp_code` 없이 검색하면 **기간이 3개월로 제한**되고, 한 페이지 최대 100건(`page_count` ≤ 100)이다.
- 전 종목 수집처럼 요청이 많을 때는 요청 사이에 짧은 대기를 두고, 020이 나오면 그날 수집을 멈추는 로직을 넣는다.

## 7. 자주 쓰는 공통 인자와 코드

| 인자 | 의미 | 값 |
|---|---|---|
| `corp_code` | **고유번호(8자리)**. 종목코드(6자리)가 아니다 | 아래 8절의 고유번호 파일에서 종목코드 → 고유번호로 변환 |
| `bsns_year` | 사업연도(4자리) | 대부분 2015년 이후부터 제공. 일부 API는 2023년 3분기 이후 또는 2026년 5월 이후부터 제공(각 API 문서 참고) |
| `reprt_code` | 보고서 코드 | `11013` 1분기보고서, `11012` 반기보고서, `11014` 3분기보고서, `11011` 사업보고서 |
| `fs_div` | 개별/연결 구분 | `OFS` 재무제표(개별), `CFS` 연결재무제표 |
| `idx_cl_code` | 재무지표 분류 | `M210000` 수익성, `M220000` 안정성, `M230000` 성장성, `M240000` 활동성 |
| `bgn_de`, `end_de` | 검색 시작·종료일 (YYYYMMDD) | 주요사항보고서 계열과 공시검색에서 사용 |
| `corp_cls` | 법인구분 | `Y` 유가증권, `K` 코스닥, `N` 코넥스, `E` 기타 |
| `pblntf_ty` | 공시유형 (공시검색) | `A` 정기공시, `B` 주요사항보고, `C` 발행공시, `D` 지분공시, `E` 기타공시, `F` 외부감사관련, `G` 펀드공시, `H` 자산유동화, `I` 거래소공시, `J` 공정위공시. 상세 유형 코드표는 [01_공시정보.md](01_공시정보.md#2019001) |

**접수번호(`rcept_no`, 14자리)** 로 공시 원문을 웹에서 열 수 있다: `https://dart.fss.or.kr/dsaf001/main.do?rcpNo={접수번호}`

## 8. 고유번호(corp_code) 얻기

거의 모든 API가 종목코드가 아니라 **DART 고유번호**를 받는다. [고유번호 API](01_공시정보.md#2019018)(`corpCode.xml`)는 전체 회사 목록을 ZIP 파일로 주며, 그 안의 `CORPCODE.xml`에 `corp_code`, `corp_name`, `corp_eng_name`, `stock_code`(상장사만 6자리), `modify_date`가 들어 있다. 하루 한 번 받아 저장해 두고 종목코드 → 고유번호 변환표로 쓴다.

## 9. 파이썬 예제

```python
import io
import os
import zipfile
import xml.etree.ElementTree as ET

import pandas as pd
import requests
from dotenv import load_dotenv

load_dotenv()
KEY = os.environ["DART_API_KEY"]
BASE = "https://opendart.fss.or.kr/api"


def dart_get(name: str, **params) -> dict:
    """JSON API 호출. status 000 이 아니면 예외 (013 '데이터 없음'은 빈 결과로 처리)."""
    r = requests.get(f"{BASE}/{name}.json", params={"crtfc_key": KEY, **params}, timeout=30)
    r.raise_for_status()
    d = r.json()
    if d["status"] == "013":
        return {**d, "list": []}
    if d["status"] != "000":
        raise RuntimeError(f"{name}: {d['status']} {d['message']}")
    return d


def corp_codes() -> pd.DataFrame:
    """고유번호 전체 목록 (ZIP 안의 CORPCODE.xml)."""
    r = requests.get(f"{BASE}/corpCode.xml", params={"crtfc_key": KEY}, timeout=60)
    with zipfile.ZipFile(io.BytesIO(r.content)) as z:
        root = ET.fromstring(z.read(z.namelist()[0]))
    rows = [{c.tag: (c.text or "").strip() for c in item} for item in root.iter("list")]
    return pd.DataFrame(rows)


codes = corp_codes()
samsung = codes.loc[codes["stock_code"] == "005930", "corp_code"].iloc[0]   # 00126380

# 공시검색: 최근 정기공시
disc = dart_get("list", corp_code=samsung, bgn_de="20260101", end_de="20261030", pblntf_ty="A", page_count=100)
print(pd.DataFrame(disc["list"])[["rcept_dt", "report_nm", "rcept_no"]])

# 단일회사 전체 재무제표 (2025 사업보고서, 연결)
fs = dart_get("fnlttSinglAcntAll", corp_code=samsung, bsns_year="2025", reprt_code="11011", fs_div="CFS")
df = pd.DataFrame(fs["list"])
df["thstrm_amount"] = pd.to_numeric(df["thstrm_amount"].str.replace(",", ""), errors="coerce")
```

## 10. 이 문서에 없는 것

- 사이트의 공지사항, FAQ, Q&A, 변동내역알림 게시판 내용은 포함하지 않았다. API 변경 이력은 [변동내역알림](https://opendart.fss.or.kr/cop/bbs/selectArticleList.do?bbsId=B0000000000000000004)에서 확인한다.
- 각 API 응답 필드의 정확한 값 형식(단위, 부호 표기 등)은 원문 페이지와 실제 응답을 함께 확인하는 것이 안전하다.

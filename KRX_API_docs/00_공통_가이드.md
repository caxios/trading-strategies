# KRX 데이터 수집 및 pykrx 스크래핑 공통 가이드

> 이 문서는 본 프로젝트에서 한국거래소(KRX)의 과거 10년 이상(2014~2026) 시세, 수급, 마스터 데이터를 수집하고 정제하기 위해 사용하는 **KRX 웹 스크래핑 구조 및 `pykrx` 라이브러리 사용 가이드**입니다.

---

## 1. 개요 및 수집 방식

### 왜 공식 Open API가 아닌 `pykrx` 스크래핑인가?
* **공식 API의 한계:** 공공데이터포털 등의 KRX 공식 API는 일일 호출 한도가 제한적이거나, 과거 장기 시계열(10년치 전 종목 일별 수급 및 틱/호가 정보)을 대량으로 한 번에 수집하기에 부적합합니다.
* **`pykrx` 라이브러리의 역할:** `pykrx`는 한국거래소 정보데이터시스템([data.krx.co.kr](http://data.krx.co.kr))의 웹 엔드포인트(OTP 발급 후 POST 조회 방식)를 파이썬 환경에서 간편하게 조회할 수 있도록 감싼 오픈소스 웹 스크래퍼입니다.
* **본 프로젝트의 데이터 범위:** 2014년 1월부터 최신일까지 코스피(KOSPI)와 코스닥(KOSDAQ) 전 종목의 **일별 시세(OHLCV)**, **투자주체별(외국인, 기타외국인, 연기금, 투신 등) 매매금액**, **지수**, **업종 분류**, **상장폐지 종목 마스터**를 완전하게 구축하고 있습니다.

## 2. 인증 및 계정 세션 관리 (`.env`)

KRX 정보데이터시스템은 대량 조회 시 로그인 인증 세션을 요구합니다.

### 2.1 환경변수 설정 (`.env`)
프로젝트 루트의 `.env` 파일에 KRX 회원 계정 정보가 등록되어 있어야 합니다.
```env
KRX_ID=your_krx_id
KRX_PW=your_krx_password
```

### 2.2 코드 내 임포트 순서 (중요)
`pykrx` 라이브러리는 **임포트되는 순간** 환경변수(`KRX_ID`, `KRX_PW`)를 참조하여 자동 로그인을 시도합니다. 따라서 반드시 `pykrx`를 임포트하기 전에 `.env`를 먼저 로드해야 합니다.
```python
from pathlib import Path
from dotenv import load_dotenv

ROOT = Path(__file__).resolve().parent
load_dotenv(ROOT / ".env")  # 반드시 pykrx 임포트 전에 실행!

from pykrx import stock     # 자동 로그인 수행
```

### 2.3 단일 세션 제약 (주의)
> [!WARNING]
> KRX 정보데이터시스템은 **1개 계정당 단 1개의 세션만 유지**됩니다.
> 만약 `fetch_flow_history.py`와 `fetch_krx_meta.py` 등 두 개 이상의 스크립트를 동시에 병렬로 실행하면, 뒤에 로그인한 프로세스가 앞선 프로세스의 세션을 끊어버려 `ConnectionError` 또는 빈 데이터 반환 오류가 발생합니다. **반드시 순차적으로 1개 프로세스만 실행해야 합니다.**

## 4. `pykrx` 핵심 API 함수 명세

본 프로젝트의 수집 파이프라인에서 사용하는 주요 `pykrx` 함수와 사용법입니다.

### 4.1 전 종목 일별 시세 (OHLCV)
```python
from pykrx import stock

df = stock.get_market_ohlcv(date="20240102", market="KOSPI")  # market: "KOSPI" 또는 "KOSDAQ"
```
* **반환 DataFrame 컬럼:** `시가`, `고가`, `저가`, `종가`, `거래량`, `거래대금`, `등락률` (인덱스는 종목 티커)
* **주의사항:** 휴장일이거나 데이터 미집계 시 빈 DataFrame(`df.empty == True`)이 반환되므로 이를 확인하여 휴장일을 판별합니다.

### 4.2 전 종목 투자주체별 거래실적
```python
from pykrx import stock

# 특정 일자 특정 투자주체의 전 종목 순매수/매수/매도 대금
df = stock.get_market_net_purchases_of_equities_by_ticker(
    fromdate="20240102",
    todate="20240102",
    market="KOSPI",
    investor="외국인"  # 또는 "기타외국인", "연기금", "투신", "개인", "기관합계"
)
```
* **반환 DataFrame 컬럼:** `매도거래대금`, `매수거래대금`, `순매수거래대금`, `매도거래량`, `매수거래량`, `순매수거래량`
* **주의사항:** 해당 거래일에 거래가 전혀 없었던 종목은 행 자체가 반환되지 않습니다(즉, 결측이 아니라 0으로 처리해야 함).

### 4.3 시장 지수 시세
```python
from pykrx import stock

# KOSPI 지수: "1001", KOSDAQ 지수: "2001"
df_kospi = stock.get_index_ohlcv_by_date("20140101", "20261022", "1001", name_display=False)
```

### 4.4 월별 업종 분류 스냅샷
```python
from pykrx import stock

df_sector = stock.get_market_sector_classifications("20240131", market="KOSPI")
```
* **반환 DataFrame 컬럼:** `종목명`, `업종명`, `시가총액`

### 4.5 상장폐지 종목 및 기본정보 크롤러 (pykrx 내부 core 호출)
생존편향(Survivorship bias)을 없애기 위해 거래소 상폐 종목 및 상세 마스터를 직접 호출합니다.
```python
from pykrx.website.krx.market.core import 상폐종목검색, 전종목기본정보

# 상장폐지 전 종목 목록
delisted_df = 상폐종목검색()  # 종목코드, 종목명, 시장구분 반환

# 전 종목 기본 스펙 (증권구분: 보통주, 우선주, 선박투자회사, 리츠 등)
basic_info_df = 전종목기본정보()
```

## 5. 투자주체 코드 매핑 및 정제 규칙

`pykrx 1.2.9` 버전 기준으로 KRX의 투자주체 코드는 다음과 같이 매핑되어 있으므로 퀀트 분석 시 주의해야 합니다.

### 5.1 외국인 그룹 (`FOR`)
* KRX 원천 데이터에는 **"외국인"**과 **"기타외국인(코드 9001)"**이 별도로 분리되어 있습니다.
* `pykrx`에서 `"외국인"`만 조회하면 기타외국인이 누락되므로, 학술/실무 표준에 맞추려면 반드시 **`외국인 + 기타외국인`을 합산**해야 완전한 외국인 순매수가 됩니다.

### 5.2 기관 그룹 (`INST`)
* `pykrx`의 `"기관합계"`에는 증권사 자기자본 매매(금융투자, LP) 등 단타성/유동성 공급 물량이 섞여 있어 잡음(Noise)이 심합니다.
* 따라서 본 연구에서는 장기 투자 성향을 가진 진짜 스마트머니인 **`연기금(국가·지자체 포함) + 투신`**을 개별 조회하여 합산해 사용합니다.

### 5.3 거래 없음 vs 거래정지 (결측치) 구분 원칙
* **시세는 거래되었는데(거래량 > 0) 투자자 파일에 특정 종목이 없는 경우:**
  👉 그 주체가 그날 해당 종목을 1주도 사거나 팔지 않은 것이므로 매수/매도/순매수 = **0원**으로 채웁니다.
* **종목 자체가 거래정지(거래량 = 0 또는 가격 결측)인 경우:**
  👉 0원이 아니라 **결측(NaN)**으로 두어 계산 분모에서 올바르게 배제합니다.

## 6. 크롤링 안정성 확보 기법 (Rate Limiting & Retry)

KRX 정보데이터시스템은 과도한 연속 요청 시 일시적으로 IP를 차단하거나 연결을 끊습니다. 프로젝트의 수집 스크립트는 이를 방지하기 위해 래퍼 함수(`call`)를 사용합니다.

```python
import time

REQUEST_INTERVAL = 0.7  # KRX 요청 간 기본 대기(0.7초)
RETRIES = 4

def call(fn, *args, **kwargs):
    """요청 간 딜레이 보장 + 실패 시 점진적 지수 백오프(Exponential Backoff) 재시도"""
    for i in range(RETRIES):
        try:
            df = fn(*args, **kwargs)
            time.sleep(REQUEST_INTERVAL)
            return df
        except Exception as e:
            wait = 5 * (i + 1)  # 5초, 10초, 15초, 20초 대기 후 재시도
            print(f"  요청 실패 ({e.__class__.__name__}) → {wait}초 후 재시도")
            time.sleep(wait)
    raise RuntimeError(f"{fn.__name__} 재시도 {RETRIES}회 최종 실패")
```

## 7. 주요 수집 스크립트 실행 방법

모든 스크립트는 이미 다운로드된 날짜 파일이 존재하면 자동으로 건너뛰므로(Resume 지원), 중단되더라도 언제든 다시 실행하면 이어받기가 가능합니다.

```bash
# 1. 일별 시세(OHLCV) 및 외인/기관 4종 투자자 거래 수집 (2014년~현재)
python strategy2/code/fetch_flow_history.py

# 2. 지수 시세, 월별 업종 스냅샷, 상폐 및 기본 마스터 수집
python strategy2/code/fetch_krx_meta.py

# 3. 최근 2년 투자자별 히스토리 수집 (대체용)
python fetch_investor_history.py --start 20240101 --end 20251231
```

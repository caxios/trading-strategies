## 0. 이 보고서의 위치와 한눈에 보는 결론

### 이 절의 역할
연구 전체는 "0단계 계획 고정 → 1단계 데이터 보강 → 2단계 변수·팩터 구성 → 3단계 평균 수익률 분석 → 4단계 꼬리 위험 분석 → 5단계 강건성·준 표본 밖 검증 → 6단계 논문 작성 → 7단계 미래 데이터 검증" 순서로 진행된다. 이 보고서는 **3단계와 4단계**, 즉 논문의 본 결과를 담는다. 이 절은 보고서를 다 읽지 않아도 핵심을 알 수 있게 결론을 먼저 요약한다.

### 이 절에서 하는 일
연구 질문과 그 답을 표 하나로 정리한다.

| 연구 질문 | 답 | 근거 (4절·5절) |
|---|---|---|
| 외국인이 극단적으로 판 종목은 이후 20일 동안 시장보다 크게(−20% 이상) 뒤처질 확률이 높은가? | **그렇다.** 통제변수 11개를 넣어도 +0.98%p (t 6.30). 신호 없는 종목의 기준 확률 3.10%의 약 1.3배 | H1 지지 |
| 외국인은 판 쪽이 산 쪽보다 위험한가? | **그렇다.** 차이 +0.72%p (t 4.04) | H2 지지 |
| 개인은 산 쪽이 판 쪽보다 위험한가? | **그렇다.** 차이 +0.97%p (t 4.14) | H4 지지 |

**한 문장 요약:** 투자주체별 수급은 거래비용을 넘는 평균 수익률 정보는 없지만, **외국인 순매도와 개인 순매수는 이후 한 달 안의 큰 하락 위험을 예측한다.**

## 2. 변수

### 이 절의 역할
3절의 모형과 4·5절의 결과표에 나오는 모든 변수를 정의한다. 아래 수식마다 그 수식에 쓰인 기호를 빠짐없이 설명하므로, 다른 절을 보지 않아도 의미를 알 수 있다.

### 이 절에서 하는 일
수급 신호, 결과변수, 통제변수를 차례로 정의한다.

### 2.1 순매수 강도와 극단 신호

$$x^{j}_{i,d} = \frac{N^{j}_{i,d}}{M_{i,d}}$$

| 기호 | 뜻 |
|---|---|
| $x^{j}_{i,d}$ | 투자주체 $j$의 종목 $i$에 대한 신호일 $d$의 순매수 강도 |
| $j$ | 투자주체. 외국인($F$), 기관합계($I$), 개인($R$) |
| $i$ | 종목 |
| $d$ | 신호일. 그날 장이 끝난 뒤 투자주체별 매매 데이터가 공개된다 |
| $N^{j}_{i,d}$ | 투자주체 $j$의 $d$일 종목 $i$ 순매수 거래대금(원) = 매수 거래대금 − 매도 거래대금. 거래가 없으면 0 |
| $M_{i,d}$ | 종목 $i$의 $d$일 종가 기준 시가총액(원) |

**의미와 용도.** 종목 크기에 비해 그 투자주체가 얼마나 많이 샀는지(+) 또는 팔았는지(−)를 나타낸다. 금액을 그대로 쓰면 대형주가 항상 상위에 오므로 시가총액으로 나눈다. 아래 극단 신호와 5.1절 수익률 회귀의 재료다.

$$S^{j}_{i,d} = \mathbf{1}\{x^{j}_{i,d}\text{가 같은 날·같은 시장에서 하위 10\%}\},\qquad B^{j}_{i,d} = \mathbf{1}\{x^{j}_{i,d}\text{가 같은 날·같은 시장에서 상위 10\%}\}$$

| 기호 | 뜻 |
|---|---|
| $S^{j}_{i,d}$ | 극단 순매도 신호. 종목 $i$가 $d$일 투자주체 $j$에게 가장 많이(시가총액 대비) 팔린 10%에 들면 1, 아니면 0 |
| $B^{j}_{i,d}$ | 극단 순매수 신호. 가장 많이 사들여진 10%에 들면 1, 아니면 0 |
| $\mathbf{1}\{\cdot\}$ | 괄호 안 조건이 참이면 1, 거짓이면 0 |
| $x^{j}_{i,d}$ | 투자주체 $j$의 종목 $i$ 순매수 강도 = $d$일 순매수 거래대금 ÷ 시가총액 |
| 같은 날·같은 시장 | 신호일 $d$에 같은 시장(KOSPI 또는 KOSDAQ)에 속한 유니버스 종목끼리만 순위를 매긴다 |

**의미와 용도.** 4단계 꼬리 위험 모형의 설명변수다. $S$와 $B$가 모두 0인 나머지 80% 종목이 비교 기준이 된다.

### 2.2 시장 대비 초과수익률과 꼬리 사건

$$R^{h}_{i,d} = \prod_{t=d+2}^{d+1+h}(1+r_{i,t}) - 1,\qquad e^{h}_{i,d} = R^{h}_{i,d} - \frac{1}{n_{d,m}}\sum_{l\in U_{d,m}} R^{h}_{l,d}$$

| 기호 | 뜻 |
|---|---|
| $R^{h}_{i,d}$ | 신호일 $d$ 다음 날($d+1$일) 종가에 종목 $i$를 사서 $h$영업일 보유한 누적 수익률 |
| $h$ | 보유 영업일 수 (1, 5, 20, 60) |
| $t$ | 보유 중 각 영업일. 진입 다음 날인 $d+2$일부터 $d+1+h$일까지 |
| $r_{i,t}$ | 종목 $i$의 $t$일 일간 수익률 (KRX 등락률 ÷ 100). 거래정지·상장폐지 이후는 0 |
| $\prod$ | 곱. 일간 수익률을 복리로 이어 붙인다 |
| $e^{h}_{i,d}$ | 종목 $i$의 $h$일 시장 대비 초과수익률 |
| $U_{d,m}$ | 신호일 $d$에 시장 $m$(종목 $i$가 속한 KOSPI 또는 KOSDAQ)의 유니버스 종목 집합 |
| $n_{d,m}$ | $U_{d,m}$의 종목 수 |
| $l$ | $U_{d,m}$에 속한 각 종목 |

**의미와 용도.** $e$는 같은 날 같은 시장의 모든 종목을 같은 금액씩 산 것보다 얼마나 더 벌었는지(잃었는지)다. 시장 전체의 등락을 빼고 종목 고유의 성과만 본다. 아래 꼬리 사건과 5.1절 수익률 회귀의 종속변수다.

$$Y_{i,d} = \mathbf{1}\{e^{20}_{i,d} \le -0.20\}$$

| 기호 | 뜻 |
|---|---|
| $Y_{i,d}$ | 꼬리 사건. 신호일 $d$ 다음 날 종가에 종목 $i$를 사서 20영업일 보유했을 때 시장 대비 20%포인트 이상 뒤처지면 1, 아니면 0 |
| $e^{20}_{i,d}$ | 20영업일 시장 대비 초과수익률 = 종목의 20일 누적수익률 − 같은 날 같은 시장 유니버스 전 종목의 20일 누적수익률 평균 |
| $\mathbf{1}\{\cdot\}$ | 조건이 참이면 1, 거짓이면 0 |

**의미와 용도.** "사서 한 달 안에 시장 대비 크게 물리는 사건"이다. 4단계 주 분석의 종속변수다. 전체 표본에서 이 사건의 비율은 4.49%, 극단 신호가 없는 종목만 보면 약 3.1%다.

### 2.3 급락 위험 지표 (보조 결과변수)

$$w_{i,t} = \ln\!\left(1 + r_{i,t} - \hat\beta_{i,d}\,r_{m,t}\right)$$

| 기호 | 뜻 |
|---|---|
| $w_{i,t}$ | 종목 $i$의 $t$일 고유 로그수익률. 시장 움직임으로 설명되는 부분을 뺀 나머지 |
| $r_{i,t}$ | 종목 $i$의 $t$일 일간 수익률 |
| $r_{m,t}$ | 종목 $i$가 속한 시장의 $t$일 시가총액 가중 지수 수익률 (전날 시가총액으로 가중. KRX 공식 지수와 일수익률 상관 KOSPI 1.0000, KOSDAQ 0.9996) |
| $\hat\beta_{i,d}$ | 종목 $i$의 베타. 신호일 $d$까지 과거 250영업일(최소 120일)의 일간 수익률로 추정. 보유기간 정보는 쓰지 않음 |
| $t$ | 보유기간의 각 영업일 ($d+2$일부터 $H$일) |
| $\ln$ | 자연로그 |

$$\text{NCSKEW}_{i,d} = -\frac{n(n-1)^{3/2}\sum_t w_{i,t}^3}{(n-1)(n-2)\left(\sum_t w_{i,t}^2\right)^{3/2}},\qquad \text{DUVOL}_{i,d} = \ln\!\left[\frac{(n_u-1)\sum_{\text{down}} w_{i,t}^2}{(n_d-1)\sum_{\text{up}} w_{i,t}^2}\right]$$

| 기호 | 뜻 |
|---|---|
| $\text{NCSKEW}_{i,d}$ | 신호일 $d$ 이후 보유기간 동안 종목 $i$ 고유 수익률 분포의 음의 왜도. 클수록 아래로 긴 꼬리(급락)가 있다 |
| $\text{DUVOL}_{i,d}$ | 같은 기간 하락일 변동성 ÷ 상승일 변동성의 로그. 클수록 떨어질 때 더 크게 움직인다 |
| $w_{i,t}$ | 종목 $i$의 $t$일 고유 로그수익률 = $\ln(1 + r_{i,t} - \hat\beta_{i,d} r_{m,t})$ |
| $n$ | 보유기간 안 관측 영업일 수 (20일 또는 60일 기간; 각각 최소 15일, 45일) |
| $\sum_t$ | 보유기간 안 모든 영업일에 대한 합 |
| down / up | $w_{i,t}$가 보유기간 평균보다 낮은 날 / 높은 날 |
| $n_d$, $n_u$ | 하락일 수 / 상승일 수 |

**의미와 용도.** 기존 급락 위험 연구에서 쓰는 표준 지표다. 꼬리 사건 $Y$와 같은 방향의 결론이 나오는지 확인하는 보조 결과변수로 쓴다.

## 3. 방법

### 이 절의 역할
2절의 변수로 가설을 검정하는 절차를 설명한다. 모든 절차는 계획서 5·6절에 미리 고정된 것이며, 결과를 본 뒤 바꾸지 않았다.

### 이 절에서 하는 일
꼬리 위험 모형, t값 계산, 다중검정 보정, 동등성 검정, 수익률 회귀, 수급 팩터 회귀를 차례로 설명한다.

### 3.1 꼬리 위험 모형: 날짜별 횡단면 선형확률모형

$$Y_{i,d} = a_d + \beta^{j}_{S,d}\,S^{j}_{i,d} + \beta^{j}_{B,d}\,B^{j}_{i,d} + \delta_d\,\text{KOSPI}_i + \gamma_d' Z_{i,d} + \varepsilon_{i,d}$$

| 기호 | 뜻 |
|---|---|
| $Y_{i,d}$ | 꼬리 사건. 신호일 $d$ 다음 날 종가에 종목 $i$를 사서 20영업일 뒤 시장 대비 초과수익률이 −20% 이하이면 1 |
| $a_d$ | $d$일 회귀의 절편. 그날 신호가 없는 평범한 종목의 기본 꼬리 확률 |
| $S^{j}_{i,d}$ | 극단 순매도 신호. 투자주체 $j$의 순매수 강도(순매수 거래대금 ÷ 시가총액)가 그날 같은 시장에서 하위 10%이면 1 |
| $B^{j}_{i,d}$ | 극단 순매수 신호. 같은 기준으로 상위 10%이면 1 |
| $\beta^{j}_{S,d}$, $\beta^{j}_{B,d}$ | $d$일 하루치 회귀의 신호 계수. 다른 변수가 같을 때 극단 순매도(순매수) 종목의 꼬리 확률이 평범한 종목보다 몇 %p 높은가 |
| $\text{KOSPI}_i$ | 종목 $i$가 KOSPI이면 1, KOSDAQ이면 0 |
| $\delta_d$ | 시장 더미의 계수 |
| $Z_{i,d}$ | 2.4절 통제변수 11개 (크기, 가치, 모멘텀, 단기 반전, 신호일 수익률, 진입일 수익률, 과거 변동성, 베타, 유동성, 회전율, 과거 왜도) |
| $\gamma_d$ | 통제변수 계수 벡터. $\gamma_d' Z_{i,d}$는 각 통제변수 × 계수의 합 |
| $\varepsilon_{i,d}$ | 설명되지 않은 나머지 |
| $j$ | 투자주체 ($F$ 외국인, $I$ 기관, $R$ 개인) |

**의미와 용도.** 결과가 0/1인 변수를 일반 선형회귀로 푸는 선형확률모형이다. 계수가 바로 "확률이 몇 %p 높아지는가"로 읽힌다. 하루씩 따로 회귀하므로 그날 시장 전체에 닥친 충격은 절편 $a_d$에 흡수된다. 투자주체마다 따로 돌리는 "단독 모형"과, 세 투자주체의 신호 6개를 한꺼번에 넣는 "결합 모형"을 모두 추정한다. NCSKEW·DUVOL(2.3절)을 종속변수로 바꾼 같은 회귀도 돌린다.

### 3.2 날짜별 계수의 평균과 Newey-West t값

$$\bar\beta = \frac{1}{T}\sum_{d=1}^{T}\beta_d,\qquad t = \frac{\bar\beta}{\sqrt{\hat\Omega_{NW}/T}},\qquad \hat\Omega_{NW} = \hat\gamma_0 + 2\sum_{l=1}^{L}\left(1-\frac{l}{L+1}\right)\hat\gamma_l$$

| 기호 | 뜻 |
|---|---|
| $\beta_d$ | 3.1절 회귀를 $d$일 하루치로 추정한 관심 계수 하나. 차이 가설(예: 외국인 매도 − 매수)은 날짜마다 $\beta^{F}_{S,d} - \beta^{F}_{B,d}$를 계산해 이 자리에 넣는다 |
| $T$ | 회귀를 돌린 신호일 수 (20일 결과 466일, 60일 결과 426일) |
| $\bar\beta$ | 날짜별 계수의 평균. 결과표에 보고하는 추정치 |
| $t$ | 평균 계수가 0에서 표준오차 몇 개만큼 떨어져 있는지 |
| $\hat\Omega_{NW}$ | Newey-West 장기분산 |
| $\hat\gamma_0$ | 날짜별 계수 $\beta_d$의 분산 |
| $\hat\gamma_l$ | $l$일 떨어진 날짜 계수끼리의 공분산 |
| $L$ | 반영하는 최대 시차 = max(보유기간 − 1, 5). 20일 결과는 19, 60일 결과는 59, 1일·5일 수익률은 5 |
| $1 - l/(L+1)$ | 바틀렛 가중치. 멀리 떨어진 공분산일수록 덜 반영 |

**의미와 용도.** 같은 날 종목들은 시장 충격을 공유하므로 서로 독립이 아니다. 날짜 하나를 관측치 하나로 만들면 이 문제가 사라진다(Fama-MacBeth 방식). 그런데 연속된 신호일의 20일 보유기간은 19일이 겹쳐서 날짜별 계수끼리도 상관된다. Newey-West 분산이 이 상관만큼 표준오차를 키워 t값이 부풀려지지 않게 한다. 모든 t값은 이 식으로 계산했다.

### 3.3 주 가설 다중검정 보정 (Holm)
주 가설 H1, H2, H4의 단측 p값을 작은 순서로 $p_{(1)} \le p_{(2)} \le p_{(3)}$로 줄 세운다. $p_{(1)} \le 0.05/3$이면 첫째를 기각하고 다음으로, $p_{(2)} \le 0.05/2$이면 둘째를 기각하고 다음으로, $p_{(3)} \le 0.05$이면 셋째를 기각한다. 중간에 기준을 못 넘으면 그 뒤는 모두 기각하지 않는다.

| 기호 | 뜻 |
|---|---|
| $p_{(k)}$ | 세 주 가설의 단측 p값 중 $k$번째로 작은 값. p값은 3.2절 t값을 표준정규분포에 대입해 구한다 |
| $0.05/3, 0.05/2, 0.05$ | 단계별 기준. 남은 가설 수로 5%를 나눈 값 |

**의미와 용도.** 세 가설 중 하나라도 잘못 기각할 확률을 5% 이하로 묶는다.

### 3.4 기관 동등성 검정 (TOST)

$$z_1 = \frac{\hat\Delta - (-0.005)}{se},\qquad z_2 = \frac{0.005 - \hat\Delta}{se},\qquad p_{\text{TOST}} = \max\{P(Z>z_1),\,P(Z>z_2)\}$$

| 기호 | 뜻 |
|---|---|
| $\hat\Delta$ | 기관 극단 순매도 계수 − 기관 극단 순매수 계수의 날짜별 평균 ($\bar\beta^{I}_{S} - \bar\beta^{I}_{B}$). 기관이 판 종목이 산 종목보다 꼬리 확률이 몇 %p 높은가 |
| $se$ | $\hat\Delta$의 Newey-West 표준오차 (3.2절 방식, 시차 19) |
| $\pm0.005$ | 동등성 한계 ±0.5%p. 외국인에서 관찰된 차이(약 1%p)의 절반 |
| $Z$ | 표준정규 확률변수 |
| $p_{\text{TOST}}$ | 두 단측 검정 p값 중 큰 값. 0.05보다 작아야 "차이가 ±0.5%p 안에 있다(동등)"고 판정 |

**의미와 용도.** 보통의 t검정에서 "유의하지 않음"은 "차이가 없다"가 아니라 "차이를 확인 못 했다"는 뜻이다. "기관은 판 쪽과 산 쪽이 같다"고 주장하려면 차이가 무시할 만한 범위 안에 있음을 직접 보여야 하므로 이 검정을 쓴다.

### 3.5 평균 수익률: Fama-MacBeth 회귀

$$e^{h}_{i,d} = a_d + b^{j}_d\,q^{j}_{i,d} + \delta_d\,\text{KOSPI}_i + c_d' Z_{i,d} + u_{i,d}$$

| 기호 | 뜻 |
|---|---|
| $e^{h}_{i,d}$ | 종목 $i$의 $h$일 시장 대비 초과수익률 (신호일 다음 날 종가 진입; 같은 날 같은 시장 유니버스 평균 대비) |
| $h$ | 보유 영업일 수: 1, 5, 20 |
| $q^{j}_{i,d}$ | 투자주체 $j$의 순매수 강도(순매수 거래대금 ÷ 시가총액)를 그날 같은 시장 안 백분위 순위로 바꾸고 0.5를 뺀 값. 가장 많이 판 종목 ≈ −0.5, 가장 많이 산 종목 ≈ +0.5 |
| $b^{j}_d$ | $d$일 순매수 순위 계수. 순위 맨 아래에서 맨 위로 갈 때 초과수익률 차이 |
| $a_d$, $\delta_d$, $\text{KOSPI}_i$ | 절편, 시장 더미 계수, KOSPI 여부(1/0) |
| $Z_{i,d}$, $c_d$ | 2.4절 통제변수 11개와 그 계수 |
| $u_{i,d}$ | 설명되지 않은 나머지 |

**의미와 용도.** 순매수 신호가 다른 종목 특성과 별개로 평균 수익률을 예측하는지 본다. 날짜별 $b^{j}_d$의 평균과 t값은 3.2절 식으로 구한다(시차 max(h−1, 5)).

### 3.6 수급 팩터(FLOW)와 기존 팩터 회귀

$$\text{FLOW}^{j}_{t} = \tfrac12(R_{SH,t}+R_{BH,t}) - \tfrac12(R_{SL,t}+R_{BL,t})$$

| 기호 | 뜻 |
|---|---|
| $\text{FLOW}^{j}_{t}$ | 투자주체 $j$의 수급 팩터 $t$일 수익률. 그 투자주체가 많이 산 종목 − 많이 판 종목 |
| $t$ | 수익률이 발생하는 날. 신호일 $d$의 정보로 $d+1$일 종가에 포트폴리오를 짜므로 $t=d+2$ |
| $R_{SH,t}$, $R_{BH,t}$ | 소형주 / 대형주(시가총액 중앙값 기준) 중 순매수 강도 상위 30% 종목의 $t$일 시가총액 가중 수익률 |
| $R_{SL,t}$, $R_{BL,t}$ | 소형주 / 대형주 중 순매수 강도 하위 30%(순매도) 종목의 $t$일 시가총액 가중 수익률 |
| $\tfrac12(\cdot)$ | 소형과 대형을 같은 비중으로 섞어 크기 효과를 상쇄 |

**의미와 용도.** 순매수 신호대로 롱숏 포트폴리오를 운용했을 때의 일별 수익률이다. 매일 다시 짜는 버전과 5영업일마다 다시 짜는 버전을 만든다.

$$\text{FLOW}^{j}_{t} = \alpha^{j} + \beta_1\text{MKT}_t + \beta_2\text{SMB}_t + \beta_3\text{HML}_t + \beta_4\text{MOM}_t + \beta_5\text{STR}_t + \varepsilon_t$$

| 기호 | 뜻 |
|---|---|
| $\text{FLOW}^{j}_{t}$ | 위에서 만든 투자주체 $j$의 수급 팩터 $t$일 수익률 |
| $\alpha^{j}$ | 기존 팩터로 설명되지 않는 일평균 초과수익 |
| $\text{MKT}_t$ | 시장 팩터: 유니버스 시가총액 가중 수익률 − 무위험수익률(CD 91일물 ÷ 252) |
| $\text{SMB}_t$ | 크기 팩터: 소형주 − 대형주 (시가총액 × 장부가/시가 2×3 정렬, 매월 말 재구성) |
| $\text{HML}_t$ | 가치 팩터: 장부가/시가 상위 30% − 하위 30% |
| $\text{MOM}_t$ | 모멘텀 팩터: 과거 12개월(최근 1개월 제외) 수익률 상위 30% − 하위 30%, 매월 재구성 |
| $\text{STR}_t$ | 단기 반전 팩터: 직전 20일 수익률 하위 30% − 상위 30%, 매일 재구성 |
| $\beta_1,\dots,\beta_5$ | 각 팩터 노출도 |
| $\varepsilon_t$ | 설명되지 않은 나머지 |

**의미와 용도.** $\alpha$가 0이면 수급 팩터의 수익은 기존 팩터의 다른 모습일 뿐이다. 표준오차는 Newey-West(시차 5)다.

$$\text{FLOW}^{j,\text{net}}_{t} = \text{FLOW}^{j}_{t} - TO^{j}_{t}\times 0.00125,\qquad TO_t = \tfrac12(\tau_{SH,t}+\tau_{BH,t}) + \tfrac12(\tau_{SL,t}+\tau_{BL,t}),\qquad \tau_{p,t} = \sum_i \left|w^{\text{new}}_{i,p,t} - w^{\text{drift}}_{i,p,t}\right|$$

| 기호 | 뜻 |
|---|---|
| $\text{FLOW}^{j,\text{net}}_{t}$ | 거래비용을 뺀 수급 팩터 $t$일 수익률 |
| $TO_t$ | 롱 1원·숏 1원 기준으로 $t$일에 사고판 금액의 합 (매매 금액 비율) |
| $0.00125$ | 편도 거래비용 0.125% (왕복 0.25% = 거래세 + 수수료) |
| $\tau_{p,t}$ | 다리 $p$(SH, BH, SL, BL 중 하나)의 매매 비율 |
| $w^{\text{new}}_{i,p,t}$ | 새로 짠 포트폴리오에서 종목 $i$의 비중 |
| $w^{\text{drift}}_{i,p,t}$ | 전날 포트폴리오를 그날 가격 변화만큼 굴린 뒤의 종목 $i$ 비중 (아무것도 안 했을 때의 비중) |
| $i$ | 다리 $p$에 들어 있거나 새로 들어오는 종목 |

**의미와 용도.** 실제로 운용하면 포트폴리오를 바꿀 때마다 비용이 든다. 비용 차감 후 $\alpha$로 H8을 검정한다. 손익분기 편도 비용 = 비용 전 $\alpha$ ÷ 평균 $TO$로, 비용이 이보다 낮아야 이익이 남는다.

## 4. 4단계 결과: 꼬리 위험

### 이 절의 역할
논문의 핵심 결과다. 연구 질문 1(수급이 꼬리 위험을 예측하는가)과 질문 2(투자주체마다 비대칭이 다른가)에 답한다.

### 이 절에서 하는 일
단독 모형 결과, 가설 판정, 결합 모형, 보조 지표, 탐색 분석과의 비교를 차례로 보인다.

### 4.1 단독 모형: 극단 신호별 꼬리 확률 증가 (종속변수 $Y$, 466일)

표의 값은 3.1절 회귀를 날짜마다 돌려 얻은 계수의 평균(3.2절 $\bar\beta$)이다. "다른 통제변수 11개가 같을 때, 극단 신호가 있는 종목은 신호가 없는 평범한 종목보다 20일 안에 시장 대비 −20% 이상 뒤처질 확률이 몇 %p 높은가"를 뜻한다. 기준 확률은 신호가 없는 종목의 꼬리 사건 비율(일평균)이다.

| 투자주체 | 극단 순매도 $\beta_S$ | 극단 순매수 $\beta_B$ | 매도 − 매수 | 기준 확률 |
|---|---|---|---|---|
| 외국인 | **+0.98%p (t 6.30)** | +0.26%p (t 1.49) | **+0.72%p (t 4.04)** | 3.10% |
| 기관 | +0.16%p (t 0.53) | −0.26%p (t −1.19) | +0.41%p (t 1.96) | 3.64% |
| 개인 | +0.19%p (t 1.07) | **+1.16%p (t 6.71)** | **−0.97%p (t −4.14)** | 3.09% |

**읽는 법.**
- 외국인이 극단적으로 판 종목은 기준 확률 3.10%에 0.98%p가 더해져 약 4.1%가 된다. 상대적으로 약 32% 높다.
- 개인이 극단적으로 산 종목은 3.09%에 1.16%p가 더해진다. 상대적으로 약 37% 높다.
- 외국인이 극단적으로 산 종목, 개인이 극단적으로 판 종목, 기관의 양쪽 신호는 통제변수를 넣으면 유의하지 않다.

**해석.**
- **주 가설 세 개가 모두 지지됐다.** 외국인은 "판 쪽이 위험하다", 개인은 "산 쪽이 위험하다"는 방향 비대칭이 통제변수 11개와 실행 가능한 진입 시점(d+1 종가)에서도 유지된다.
- **H5는 대부분 기각되지 않았다.** "극단적인 수급은 방향과 관계없이 위험하다"는 보조 가설은 외국인 매도와 개인 매수에서만 성립한다. 탐색 분석에서 보였던 "외국인이 크게 산 종목도 1.2배 위험하다"는 결과는 통제변수(특히 과거 변동성, 신호일 수익률, 회전율)로 설명된다.
- **H3: 기관은 매도 쪽이 약간 더 위험한 방향이며, 차이가 0.5%p 안에 있다고 말할 수 없다.** 탐색 분석의 "기관은 판 쪽과 산 쪽이 같다"는 결론은 이 검정으로 뒷받침되지 않는다. 다만 기관의 개별 신호(+0.16%p, −0.26%p)는 둘 다 유의하지 않아, 기관 신호 자체의 위험 정보는 외국인·개인보다 훨씬 약하다.

### 4.3 결합 모형: 세 투자주체 신호를 함께 넣으면

## 5. 3단계 결과: 평균 수익률

### 이 절의 역할
연구 질문 3(수급이 평균 수익률을 예측하는가)에 답한다. 논문에서는 "평균 수익률에는 쓸 만한 정보가 없지만 꼬리 위험에는 있다"는 대비를 보이는 역할을 한다.

### 이 절에서 하는 일
Fama-MacBeth 수익률 회귀와 FLOW 팩터 회귀 결과를 보이고 H7·H8을 판정한다.

### 5.1 Fama-MacBeth: 순매수 순위 → 이후 초과수익률

표의 값은 3.5절 계수 $b^{j}$의 날짜별 평균이다. 다른 통제변수가 같을 때, 순매수 순위가 맨 아래(가장 많이 판 종목)에서 맨 위(가장 많이 산 종목)로 갈 때 $h$일 시장 대비 초과수익률의 차이다.

| 보유기간 | 외국인 | 기관 | 개인 |
|---|---|---|---|
| 1일 | **+0.050% (t 2.03)** | −0.013% (t −0.60) | −0.042% (t −1.63) |
| 5일 | +0.077% (t 1.28) | −0.069% (t −1.02) | −0.051% (t −0.77) |
| 20일 | +0.093% (t 0.65) | −0.241% (t −1.44) | +0.129% (t 0.66) |

**H7 판정:** 외국인 1일은 보정 전 단측 p 0.021로 유의하지만 본페로니 기준(0.0042)은 넘지 못한다. 5일은 유의하지 않다(p 0.10). **외국인 순매수의 수익률 예측력은 다음 날 하루, 0.05% 수준으로 매우 작다.**

### 5.2 FLOW 팩터

일수익률 기준이다. "평균"은 팩터 수익률 자체의 일평균, "α"는 3.6절 기존 팩터 회귀의 절편이다.

| 투자주체 | 리밸런싱 | 비용 전 평균 | 비용 전 α | 비용 후 α | 일평균 매매 비율 | 손익분기 편도 비용 |
|---|---|---|---|---|---|---|
| 외국인 | 매일 | +0.040% (t 0.85) | +0.069% (t 1.63) | **−0.259% (t −6.11)** | 2.62 | 0.026% |
| 외국인 | 5일 | +0.039% (t 0.90) | +0.075% (t 1.83) | +0.007% (t 0.16) | 0.54 | 0.137% |
| 기관 | 매일 | −0.001% (t −0.02) | −0.005% (t −0.12) | **−0.293% (t −7.40)** | 2.30 | — |
| 기관 | 5일 | +0.049% (t 1.29) | +0.032% (t 0.88) | −0.031% (t −0.83) | 0.50 | 0.064% |
| 개인 | 매일 | −0.025% (t −0.52) | −0.049% (t −1.06) | **−0.380% (t −8.17)** | 2.64 | — |
| 개인 | 5일 | −0.055% (t −1.27) | −0.081% (t −1.88) | −0.150% (t −3.47) | 0.55 | — |

기존 팩터 노출(비용 전, 매일 리밸런싱): 외국인 FLOW는 SMB +0.17, HML +0.15. 기관 FLOW는 STR −0.16. 개인 FLOW는 SMB −0.17, STR +0.17. 개인 FLOW가 STR에 양(+)으로 노출된다는 것은 개인이 최근 떨어진 종목을 사는 역추세 매매 성향과 맞는다.

**H8 판정과 주의점.**
- 계획서 H8의 문구는 "비용 차감 후 α = 0을 기각하지 못한다(양측)"였다. 실제 결과는 매일 리밸런싱 FLOW 세 개 모두 **α가 유의하게 음수**여서, 형식상 "가설과 불일치"로 판정된다.
- 내용상으로는 예상보다 강한 결과다. 비용을 빼면 "남는 것이 없다" 수준이 아니라 "손실"이다. 하루 매매 금액이 운용 자금의 2.3~2.6배라 편도 0.125% 비용만으로 하루 약 0.3%가 빠진다.
- 계획서의 문구를 "비용 후 α > 0이 아니다(단측)"로 정했어야 했다. 하지만 결과를 본 뒤 바꾸면 사전 등록 위반이므로 판정은 그대로 두고 이 사정을 논문에 적는다.
- 5일 리밸런싱 외국인 FLOW는 비용 전 α +0.075%(t 1.83)이고, 손익분기 편도 비용 0.137%가 실제 비용 0.125%와 거의 같다. 회전율을 낮춰도 이익이 거의 남지 않는다.

## 6. 종합 해석

### 이 절의 역할
4·5절 결과를 연구 질문 전체의 관점에서 묶어, 논문 서론과 결론에 쓸 메시지를 정한다.

### 이 절에서 하는 일
결과가 말하는 것과 말하지 않는 것을 구분한다.

**말하는 것.**
1. 투자주체별 순매수에는 **거래비용을 넘는 평균 수익률 정보가 없다.** 외국인 신호의 예측력은 다음 날 0.05% 수준이고, 실제 운용 가능한 형태(FLOW 팩터)로 만들면 비용에 잠식된다.
2. 같은 신호에는 **꼬리 위험 정보가 있다.** 외국인이 크게 판 종목과 개인이 크게 산 종목은, 크기·가치·모멘텀·단기 반전·당일과 다음 날 가격 반응·변동성·베타·유동성·회전율·과거 왜도를 모두 통제해도, 이후 20일 안에 시장 대비 −20% 이상 뒤처질 확률이 약 30~40% 높다.
3. 이 정보는 **방향에 따라 비대칭이다.** 외국인은 매도 쪽, 개인은 매수 쪽에만 있다. 정보를 가진 쪽(외국인)이 팔고 정보가 적은 쪽(개인)이 받는 손바뀜이 위험 신호라는 해석과 맞는다.
4. 기관 신호의 위험 정보는 약하다. 다만 "기관 매도와 매수가 같다"고 단정할 근거는 없다.

**말하지 않는 것.**
- 이 결과는 **인과관계가 아니다.** 외국인 매도가 하락을 일으켰는지, 외국인이 하락을 미리 알았는지는 구분하지 못한다.
- 이 결과는 **표본 내 결과다.** 가설이 같은 2년 데이터에서 나왔으므로 엄밀한 확증은 7단계 미래 표본 검증이 필요하다.
- 꼬리 사건이 평균적으로 몇 %p 늘어나는가를 말할 뿐, 개별 종목의 하락을 맞히는 예측 도구라는 뜻은 아니다. 신호가 있어도 약 96%의 종목에서는 꼬리 사건이 일어나지 않는다.

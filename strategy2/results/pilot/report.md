## 3. 필터 단계별 종목 수

**역할:** 6절의 적용 순서(유니버스 → 유동성 → 참여 → 숏커버링)대로 종목이 얼마나 남는지 보여 줍니다. 계획서 11.2절 표 1의 형식을 점검합니다.

**수행 내용:** 신호일 평균 종목 수입니다(창 60일, `filter_counts_W60.csv`).

| 단계 | 남은 종목 | 비고 |
|---|---|---|
| 상장 · 정적 조건(우선주·스팩·펀드형·외국 기업 제외) | 47.4 | |
| 거래정지 · 정리매매 아님 | 44.6 | |
| 상장 252거래일 | 41.4 | |
| 유동성(직전 20일 평균 거래대금 ≥ 10억 원) | 25.3 | 여기까지가 기준 시장 |
| 창 거래일 80% 이상 | 25.1 | |
| FOR 참여율 ≥ 5% → 숏커버링 필터 | 22.2 → 19.2 | |
| INST 참여율 ≥ 5% | 12.3 | |
| PENS 참여율 ≥ 5% | 11.3 | |
| IVTR 참여율 ≥ 5% | 0.9 | 7절 참조 |

참여율의 정의는 다음과 같습니다(계획서 6.1절).

$$\text{Part}^{g}_{i,t} = \frac{\sum_{k=0}^{W-1}\left(\text{Buy}^{g}_{i,t-k} + \text{Sell}^{g}_{i,t-k}\right)}{2 \times \sum_{k=0}^{W-1}\text{TradingValue}_{i,t-k}}$$

- $\text{Part}^{g}_{i,t}$: 종목 $i$의 최근 $W$거래일 거래에서 투자주체 그룹 $g$가 차지한 비중(0~1)입니다.
- $\text{Buy}^{g}_{i,t-k}$, $\text{Sell}^{g}_{i,t-k}$: 그룹 $g$가 종목 $i$를 $t-k$일에 매수한 금액, 매도한 금액(원)입니다.
- $\text{TradingValue}_{i,t-k}$: 종목 $i$의 $t-k$일 시장 전체 거래대금(원)입니다. 한 거래에 매수자와 매도자가 하나씩 있으므로 분모에 2를 곱합니다.
- $W$: 창 길이(60거래일)이고, $k$는 신호일부터 거슬러 올라가는 거래일 인덱스입니다.
- 의미와 용도: 이 값이 5% 미만이면 그 그룹이 거의 거래하지 않는 종목으로 보고 점수 계산에서 뺍니다.

## 4. 단계별 출력 확인 (해석 금지)

**역할:** 7~8절의 모든 단계가 값을 만들었는지, 표본 부족으로 건너뛴 단계는 무엇인지 확인합니다.

**수행 내용:** 수익률은 계획서 7.3절(변경 후)대로 신호일 단위로 계산했습니다.

$$R^{\text{ex}}_{q,t} = \frac{1}{n_{q,t}}\sum_{i \in q_t} R^{\text{ex}}_{i,t}, \qquad D_t = R^{\text{ex}}_{10,t} - R^{\text{ex}}_{1,t}$$

- $R^{\text{ex}}_{q,t}$: 신호일 $t$에 점수 분위 $q$(1~10)에 든 종목들을 다음 거래일 시가에 동일 가중으로 사서 $h$거래일 보유했을 때, 같은 규칙으로 산 기준 시장(유동성 통과 전체, 동일 가중)보다 더 번 수익률입니다.
- $q_t$, $n_{q,t}$: 신호일 $t$에 분위 $q$에 든 종목 집합과 그 종목 수입니다.
- $R^{\text{ex}}_{i,t}$: 종목 $i$의 신호일 $t$ 기준 $h$거래일 초과수익률입니다.
- $D_t$: 신호일 $t$의 10분위 − 1분위 차이입니다. 표의 "10−1 평균"은 $D_t$의 신호일 평균이고, t는 겹침을 보정한 Newey–West t(시차 $h/5$: 20일이면 4, 60일이면 12)입니다.
- 의미와 용도: "매주 점수 상위 10%를 사서 $h$거래일 보유하면 평균 몇 %를 더 벌었나"를 그대로 계산합니다.

비용 차감은 계획서 7.4절(변경 후) 식입니다.

$$R^{\text{net}}_{q,t} = R_{q,t} - \left(2c + \tau_{t} + 2\bar{s}_{q,t}\right)$$

- $R^{\text{net}}_{q,t}$, $R_{q,t}$: 분위 $q$를 신호일 $t$에 사서 $h$거래일 보유한 동일 가중 수익률의 비용 차감 후, 차감 전 값입니다.
- $c$: 편도 수수료율(기본 0.015%, 민감도 0.05%)입니다. 매수·매도 양쪽에 붙어 2를 곱합니다.
- $\tau_{t}$: 매도 결제일(보유 마지막 거래일 + 2거래일)의 증권거래세율(농특세 포함)입니다.
- $\bar{s}_{q,t}$: 분위 $q$ 종목들의 평균 반스프레드입니다(8절 2번의 하한 포함). 매수·매도 양쪽에 붙어 2를 곱합니다.
- 의미와 용도: 보유 기간마다 전부 사고 판다고 보는 보수적 비용입니다. 파일럿에서 10분위의 평균 왕복 비용은 FOR 1.10%, INST 0.73%였습니다.

|---|---|---|---|---|---|
| 8.1 10−1 평균 (NW t) | −3.0% (−1.24) | −0.8% (−0.47) | 5.0% (0.99) | −1.7% (−0.32) | 산출됨 |

## 5. 수익률 계산 손계산 대조

**역할:** 이런 연구에서 가장 위험한 오류는 에러 없이 수익률을 부풀리는 계산 버그입니다. 수익률 계산 코드(`Engine`)를 그와 다른 방법으로 짠 손계산 코드와 비교해 계산이 맞는지 확인합니다.

**수행 내용:**

- 엔진은 일간 수익률을 복리로 쌓습니다. 손계산은 패널의 수정 시가·수정 종가 수준만으로 직접 계산합니다. 보유 마지막 날 가격은 진입일 이후 마지막으로 거래된 수정 종가로 둡니다(거래정지·상폐 후에는 마지막 가격 유지).

  $$R_{i,t} = \frac{\text{Close}_{i,\,t+h}}{\text{Open}_{i,\,t+1}} - 1$$

  - $R_{i,t}$: 신호일 $t$의 점수를 보고 종목 $i$를 다음 거래일 수정 시가 $\text{Open}_{i,t+1}$에 사서, 진입일을 첫째 날로 세어 $h$번째 거래일 수정 종가 $\text{Close}_{i,t+h}$까지 보유한 수익률입니다.
  - $h$: 보유 기간(20 또는 60거래일)입니다.

  | 보유 기간 | 대상 | 최대 절대 차이 |
  |---|---|---|
  | 20거래일 | 점수 종목 2,331건 전체 | 1.3 × 10⁻¹⁵ |
  | 60거래일 | 점수 종목 2,331건 전체 | 2.9 × 10⁻¹⁵ |

- 분위·롱-숏 수익률은 이 종목 수익률의 단순 평균과 차이이므로 따로 대조할 단계가 없습니다. 이전 방식(Jegadeesh–Titman)의 주간 수익률·회전율 계산도 지난 실행에서 손계산과 일치했지만, 계획 변경으로 더 쓰지 않습니다.

## 7. 결정이 필요한 문제: 투신 단독 보조 분석

**역할:** 사전 고정 설정 때문에 계획서의 분석 하나가 사실상 수행 불가능하다는 점을 보고합니다(계획서 0절 1항: 기술적 이유가 생기면 멈추고 보고).

**수행 내용:**

- 계획서 2절은 "보조 분석으로 연기금, 투신 각각 따로 보고"를 요구합니다. 그런데 투신 단독으로는 참여율 5% 필터를 통과하는 종목이 신호일당 평균 0.9개라, 10분위를 만들 수 없었습니다. 연기금 단독은 11.3개로 돌아갔습니다.
- 파일럿 50종목 중 유동성 통과 종목이 25개라 전체 유니버스에서는 숫자가 커지겠지만, 비율로 보면 투신 단독 통과율(약 4%)은 매우 낮습니다. 전체 유니버스에서 몇 종목이 남는지 먼저 세어 보고, 신호일당 수십 종목 이하이면 아래 중 하나를 정해 주셔야 합니다.
  1. 투신 단독은 "표본 부족으로 보고 불가"로 기록하고 생략
  2. 투신 단독에만 참여율 필터를 낮춤(예: 1%). 보조 분석이라 9절 판정에는 영향이 없지만 사전 고정 값을 바꾸는 것이라 승인이 필요합니다.
- 주 분석(INST = 연기금 + 투신)은 영향이 없습니다.

## 8. 발견하고 고친 문제

**역할:** 파일럿에서 드러난 데이터·코드 문제와 처리를 기록합니다. 자세한 내용은 `logs/pilot_issues.md`에 있습니다.

**수행 내용:**

1. **상폐 펀드형 회사 41종목이 보통주로 분류돼 있었음 (4.1절).**
   - 무작위 표본에 트러스제7호가 뽑혀 발견했습니다.
   - 상폐 종목은 KRX 마스터에 증권구분이 없어, 이름 규칙에 안 걸린 선박·부동산·자원 펀드(동북아N호, 아시아N호, 바다로N호, 하이골드N호 등)가 남아 있었습니다.
   - 분류 규칙을 고치고 정제 자료를 다시 만들었습니다. 펀드형은 40종목에서 81종목, 스팩은 237종목에서 238종목이 됐습니다.
2. **슬리피지 추정치의 약 4분의 1이 0 (7.4절).** Abdi–Ranaldo 추정치에 하한을 뒀습니다.

   $$s_{i,t} = \max\left(\tfrac{1}{2}\hat{S}^{\text{AR}}_{i,t},\ \frac{1}{60}\sum_{k=0}^{59}\frac{\tfrac{1}{2}\,\text{Tick}_{i,t-k}}{\text{Close}_{i,t-k}}\right)$$

   - $s_{i,t}$: 종목 $i$의 신호일 $t$ 기준 반스프레드(편도 슬리피지) 추정치입니다.
   - $\hat{S}^{\text{AR}}_{i,t}$: 최근 60거래일 고가·저가·종가로 추정한 Abdi–Ranaldo(2017) 스프레드입니다. 평균이 음수면 0으로 둡니다.
   - $\text{Tick}_{i,t-k}$, $\text{Close}_{i,t-k}$: 그날 종가에 적용되는 KRX 호가 단위(원)와 종가(원)입니다.
   - 의미와 용도: 스프레드는 한 틱보다 좁을 수 없으므로, 추정치가 이 하한보다 작으면 하한으로 바꿔 비용을 과소평가하지 않게 합니다.
   - 적용 후 반스프레드 분위(5·25·50·75·95%)는 0.07·0.10·0.21·0.44·1.02%입니다.
   - 2023-01-25 이후 호가 단위표는 출처로 확인했습니다. 그 이전 표 중 일부 구간(코스닥 5만 원 이상 100원 등)은 다시 대조하지 못했습니다.
3. **8.5절 해석 문구의 논리 오류.** 처음에 "공매도 금지 기간에는 숏커버링 제외 비율이 낮아야 한다"고 적었지만, 금지 기간에도 기존 공매도의 상환은 계속되므로 틀린 예측이었습니다. 방향 예측 없는 서술로 고쳤고, `logs/assumptions.md` 7절에 기록했습니다.
4. **표본 부족 분석의 안전장치.** 이중 정렬(신호일당 25종목)과 시장 분리(10종목)는 조건을 만족하는 신호일이 30개 미만이면 "표본 부족"으로 기록하고 건너뜁니다. Fama–MacBeth는 관측이 적은 신호일에 업종 더미를 빼고 그 횟수를 보고합니다.

## 9. 8.5절 숏커버링 보조 분석 (파이프라인 확인, 해석 금지)

**역할:** 연구자가 승인한 8.5절 보조 분석(필터 없는 FOR, 필터로 제외된 종목의 성과, 공매도 금지 기간별 제외 비율)이 끝까지 계산되는지 확인합니다. 이 분석은 9절 공개 판정에 쓰지 않습니다.

**수행 내용:**

먼저 4.4절 숏커버링 필터의 정의입니다(대차잔고는 부록 A-1에 따라 하루 늦춰 씁니다).

$$\text{ShortCover}_{i,t} = \mathbf{1}\left[\ \textstyle\sum_{k=0}^{W-1}\text{NetBuy}^{\text{FOR}}_{i,t-k} > 0 \ \text{그리고}\ -\Delta\text{Loan}_{i,t} \ge 0.5 \times \textstyle\sum_{k=0}^{W-1}\text{NetBuy}^{\text{FOR}}_{i,t-k}\ \right], \qquad \Delta\text{Loan}_{i,t} = \text{Loan}_{i,t-1} - \text{Loan}_{i,t-W}$$

- $\text{ShortCover}_{i,t}$: 종목 $i$가 신호일 $t$에 숏커버링 의심 종목이면 1(제외), 아니면 0입니다.
- $\mathbf{1}[\cdot]$: 괄호 안 조건이 모두 참이면 1인 지시함수입니다.
- $\text{NetBuy}^{\text{FOR}}_{i,t-k}$: 외국인 합계의 종목 $i$ $t-k$일 순매수 금액(원)입니다.
- $\text{Loan}_{i,t}$: 종목 $i$의 $t$일 대차잔고 금액(원)입니다. $t$일 값은 $t+1$일에 공개된다고 보고 $t-1$일 값까지만 씁니다.
- $\Delta\text{Loan}_{i,t}$: $t-W$일부터 $t-1$일 사이 대차잔고 변화(원)이고, $-\Delta\text{Loan}_{i,t}$는 감소분입니다.
- $W$: 창 길이(60거래일)입니다.
- 의미와 용도: 순매수의 절반 이상이 대차잔고 감소로 설명되는 종목을 숏커버링으로 보고 FOR 점수에서 뺍니다.

제외된 종목의 성과는 아래 두 값으로 봅니다(계획서 8.5절).

$$\bar{R}^{\text{ex}}_{\mathcal{E}} = \frac{1}{|\mathcal{E}|}\sum_{(i,t)\in\mathcal{E}} R^{\text{ex}}_{i,t}, \qquad \text{Hit}_{\mathcal{E}} = \frac{1}{|\mathcal{E}|}\sum_{(i,t)\in\mathcal{E}}\mathbf{1}\left[R^{\text{ex}}_{i,t} > 0\right]$$

- $\mathcal{E}$: 숏커버링 필터로 제외된 모든 (종목, 신호일) 쌍의 집합이고, $|\mathcal{E}|$는 그 개수입니다.
- $R^{\text{ex}}_{i,t}$: 종목 $i$의 신호일 $t$ 기준 $h$거래일 초과수익률입니다.
- $\bar{R}^{\text{ex}}_{\mathcal{E}}$, $\text{Hit}_{\mathcal{E}}$: 제외 종목의 평균 초과수익률과 시장을 이긴 비율입니다.

파이프라인 출력은 다음과 같습니다.

| 항목 | 20거래일 | 60거래일 |
|---|---|---|
| FOR(필터 적용) 10−1 평균 (NW t) | −3.0% (−1.24) | 5.0% (0.99) |
| FOR(필터 없음) 10−1 평균 (NW t) | −0.4% (−0.14) | 8.9% (1.38) |
| 제외된 (종목, 신호일) 쌍 | 314쌍, 신호일당 3.0종목 | 같음 |
| 제외 종목 평균 초과수익률 $\bar{R}^{\text{ex}}_{\mathcal{E}}$, 적중률 $\text{Hit}_{\mathcal{E}}$ | 2.9%, 0.47 | 7.3%, 0.47 |
| 제외 종목 신호일 단위 초과수익률 (NW t) | 2.1% (1.45) | 7.0% (2.00) |
| 제외 종목의 필터 없는 점수 분위 | 10분위 103쌍, 9분위 44쌍 … 1분위 1쌍 | 같음 |
| 제외 비율: 공매도 전면 금지 기간 / 그 밖 | 14.7% (신호일 42) / 12.3% (신호일 63) | 같음 |

- 파이프라인 관점의 관찰:
  - 제외 종목이 필터 없는 점수의 상위 분위에 몰려 있습니다. 필터가 "순매수는 크지만 대차잔고도 크게 줄어든 종목"을 고르는 구조이므로 예상과 맞습니다.
  - 따라서 필터를 켜고 끄면 10분위 구성이 크게 달라집니다. 설계 확인 구간에서 필터의 영향이 클 수 있다는 신호이고, 8.5절을 추가한 이유와 맞습니다.
  - 수익률 크기와 방향은 50종목 표본이라 해석하지 않습니다.
